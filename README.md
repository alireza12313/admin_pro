# پنل مدیریت آرمان

قالب پنل مدیریت فروش، راست‌چین و فارسی، با پوسته‌ی تیره و روشن. فقط فرانت‌اند است و برای اتصال به بک‌اند آماده شده.

## اجرا
فایل `index.html` را در مرورگر باز کنید. نیازی به نصب چیزی نیست.
نسخه‌ی تک‌فایل هم در پوشه‌ی `single-file` هست.

## ساختار
- `index.html`: ساختار صفحه‌ها
- `assets/css/style.css`: استایل‌ها (رنگ‌ها در متغیرهای `:root` بالای فایل)
- `assets/js/app.js`: منطق و داده‌های نمونه
- `assets/images/`: تصاویر مخصوص مارکت (۲ اسکرین ۷۰۰×۷۰۰، آیکون ۸۰×۸۰، تصویر ۴۰۰×۴۰۰)

## صفحه‌ها
داشبورد، تحلیل و گزارش‌ها، سفارش‌ها، محصولات، مشتریان، فاکتورها، کدهای تخفیف، پیام‌ها، نظرات، تقویم، وظایف، تیم و دسترسی‌ها، تنظیمات، و صفحه‌ی ورود.

## اتصال به بک‌اند
- داده‌های نمونه در `app.js` تعریف شده‌اند (`orders`، `names`، `CP`، `TM` و ...). برای اتصال، آن‌ها را با پاسخ API خودتان جایگزین کنید و بعد تابع `ro()` را صدا بزنید تا جدول‌ها دوباره رسم شوند.
- ورود فقط نمایشی است (دکمه‌ی `#lgb` در `app.js`). احراز هویت واقعی را باید خودتان اضافه کنید.
- تغییرات (مثل ثبت یا حذف سفارش) فعلاً فقط در حافظه‌ی مرورگر می‌مانند و ذخیره نمی‌شوند.

## نکته‌ها
- فونت وزیرمتن از Google Fonts بارگذاری می‌شود. برای کار آفلاین، فونت را کنار پروژه قرار دهید.
- رنگ اصلی از بخش تنظیمات قابل تغییر است.
